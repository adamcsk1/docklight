External bind mounts allow paths outside the stack folder, such as /etc/localtime or media folders. Host-level options remain blocked.

Docker socket mounts allow exact socket file mounts for /var/run/docker.sock or /run/docker.sock. This gives containers powerful control over the Docker host. Enable only for trusted stacks.

USB device bind mounts allow the exact host bind mount /dev/bus/usb, exposing USB devices to the container. Enable only for trusted stacks.

DBus system bus bind mounts allow the exact host bind mount /run/dbus, exposing the host system bus to the container. Enable only for trusted stacks.

Host PID namespace allows pid: host, exposing host process IDs to the container. Enable only for trusted stacks.

Privileged mode allows privileged: true, giving the container broad host access. Enable only for trusted stacks.
