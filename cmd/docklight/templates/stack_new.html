Safety permissions

Tracked in .docklight.config.yml. Keep these off unless the compose file is trusted.

External bind mounts allow paths outside the stack folder, such as /etc/localtime or media folders. Host-level options remain blocked.

Allows exact socket file mounts for /var/run/docker.sock or /run/docker.sock. This gives containers powerful control over the Docker host. Enable only for trusted stacks.

Allows the exact host bind mount /dev/bus/usb. This exposes USB devices to the container. Enable only for trusted stacks.

Allows the exact host bind mount /run/dbus. This exposes the host system bus to the container. Enable only for trusted stacks.

Allows pid: host. This exposes host process IDs to the container. Enable only for trusted stacks.

Allows privileged: true. This gives the container broad host access. Enable only for trusted stacks.

Allows security_opt entries. This can change container confinement. Enable only for trusted stacks.
